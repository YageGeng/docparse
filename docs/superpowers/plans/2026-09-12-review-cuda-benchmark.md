## 实测发现与最终结果

- [x] GPU 实测发现逐次进入通用阻塞线程池导致 CUDA 资源分配失败；改为各 Session 固定线程执行，保留原 CUDA 参数，验证线程绑定与取消时资源生命周期。
- [x] 评测遇到推理降级即拒绝成绩；三个失败尝试保留但不纳入有效成绩。

有效评测：12 份、368 页，预热后 132.492 秒，2.778 页/秒；推理失败和页错误均为 0。设备显存峰值 6649 MiB，GPU 平均利用率 44.3%。详细代码审查与逐文件数据见 [报告](../../benchmarks/2026-09-12-cuda/README.md)。
