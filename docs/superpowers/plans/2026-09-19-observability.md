# DocParse 可观测性实施计划

目标：低侵入地采集任务、背压、吞吐及推理指标，提供 Prometheus、实时监控和历史监控，并在本机 CUDA 验证。

约束：不创建 commit、不使用子代理或 worktree；保留已有前端改动；新增函数注释使用英文；数据库迁移必须由 sea-orm-cli 生成，查询使用 SeaORM/SeaQuery；Podman 容器不挂载任何数据卷（包括镜像声明的匿名卷）。

## 实施步骤

- [x] 数据库时间线：增加首次开始和最终结束时间，重试不覆盖首次开始；补充当前尝试开始/入队时间以准确统计重试和等待；更新公开任务快照与迁移回归。
- [x] 共享指标：在 common 中提供固定标签和 RAII 计时/占用工具；在共用队列、页面槽位、session manager 集中采集；取消、关闭和消费者退出正确释放计数。
- [x] 推理边界：各模型仅在真实 ORT 调用位置记录耗时和 batch，避免重复累计页面计时；采集逻辑批次消费者与物理推理的不同口径。
- [x] 服务端：安装 recorder、暴露抓取端点、后台缓存数据库队列统计、采集任务/发布/租约/PDFium 指标；实时 API 读取同一记录器，历史 API 仅允许预定义查询并限制时间范围、超时和响应大小。
- [x] 前端：增加监控页与导航；实时模式五秒刷新，历史模式选择时间窗展示曲线；区分过期数据、Prometheus 未配置、连接失败、真正的零值。
- [x] 部署验证：启动无挂载的 Prometheus 容器，用 podman cp 写入配置；启动独立本地 CUDA 服务和隔离数据库，提交真实 PDF；验证抓取、队列、耗时、推理、历史和前端；保留可复现命令和验证记录。
- [x] 完成相关测试、WASM 检查、前端构建、pre-commit；不自动提交，不干扰用户现有服务。

## 统计口径

任务终态按数据库接受的转换计数；失败尝试与最终失败分开。上传入库为 created_at，started_at 为首次领取，finished_at 为最终终态；每次重试另记排队起点与本次尝试开始。数据库失败不清零历史快照。页面容量在最后一个 PageLease 释放时归还。模型消费者忙碌保持到实际工作返回，不能随调用方取消提前释放。Prometheus 标签只含固定的模型、阶段和结果，不包含 PDF 名称、任务 ID 或错误全文。

## 验收

队列容量为一时能够观察等待，取消和关闭后占用归零；一次跨页面 batch 只记一次物理调用；首次开始时间跨重试不变，最终结束不被心跳改写；真实 CUDA 模型产生计数和耗时；Prometheus target 为 UP 且 query_range 返回历史；前端实时与历史都展示实际数据并正确处理后端不可用。

## 验证结果

- 公共模块、公式队列/会话、TSR 与服务端指标测试：42 通过，1 个依赖额外环境的测试忽略；PostgreSQL 集成测试 4 通过。
- pre-commit（平台边界、fmt、clippy）通过；WASM 编译和 WebUI 生产构建通过。
- 本机 RTX 4060 CUDA：独立端口 18080，47 页真实 PDF 首轮成功，随后三个并发上传共 141 页成功，最后构建再次验证 47 页。
- 捕获到排队任务峰值 2、页面占用 2/2、页面提交阻塞 1、模型实际活跃调用；14 种历史查询都有真实有限样本。
- 浏览器桌面与 390px 窄屏检查通过；Prometheus 停止时保留旧历史值并提示错误，恢复就绪后刷新正常。
- Prometheus 容器端口 19090，配置与数据全部在容器内，重启后历史仍在；两个新容器 Mounts 均为空。
- 保留用户原有服务及上传页面修改，无 commit。运维说明见 docs/observability.md。

## Review 修复验证

- 历史积压/年龄先按采集成功与 15 秒新鲜度筛选同一 job/instance，再聚合；真实 promtool 测试证明故障副本的旧高值不会覆盖健康副本，全部失效时返回空缺。
- 公共入队计时改为 RAII，模型与页面等待被取消也记录 outcome=cancelled；回归测试先失败后通过。
- 实时响应新增进程 UUID/角色，前端明确当前进程范围；API-only 的 worker 指标显示不可用，切换实例重置差分基线。真实 API-only 后端浏览器验证通过。
- 发布计时随临时文件跨序列化与最终 fsync 阻塞任务传递，异步等待取消不再提前结束计时。指标与存储相关测试 7 项通过。
- 最终 CUDA 构建再次成功解析 47 页真实 PDF，记录 47 次 Layout 调用与 1 次完整发布；pre-commit、WASM 检查和 WebUI 构建通过。未创建 commit。
