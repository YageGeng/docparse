# TSR 后处理与表格合成修复计划

## 目标

在纯 TSR (`external_only`) 下，对 `2303.18223v16.pdf` 完整 144 页的所有 layout table 生成结构化单元格、HTML/Markdown，并保留全部原文引用。使用实际浏览器 SDK、布局模型与 SLANet_plus ONNX 验收，不以规则解析结果替代模型拓扑。

## 步骤

1. 保存实际裁剪、模型 tokens/坐标和失败原因，逐表建立可重放输入。
2. 基于证据修复序列解码、网格归一化和坐标校准；无法从模型证据恢复时保留明确错误。
3. 原文绑定必须保留每个词的唯一引用，合并单元格由模型结构与位置共同支持，禁止用整表单格掩盖失败。
4. 加入失败类别的回归测试，检查现有外部 TSR 的输入校验和规则解析回归。
5. 用纯 TSR 跑完整浏览器端到端，要求所有检测表格均有结果；逐表检查文字归属与合并关系，报告仍存在的语义偏差。

## 边界

不创建 worktree，不创建 commit。外部声明式输入继续严格校验；模型位置噪声处理应明确限定在预测输入路径。所有修改保持原 layout 边界与原始文本事实。
