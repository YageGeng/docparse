# OpenAPI 与 Scalar 接入计划

## 设计

- 使用 `#[utoipa::path]` 标注所有业务 handler，用 `OpenApiRouter` 和 `routes!` 同时注册路由和生成文档。
- 提供 `/docs` Scalar 页面和 `/openapi.json`，文档辅助接口也使用 path 宏声明；现有 middleware 与 AppState 构造方式保持原样。
- 成功响应、错误响应、任务快照和规范化文档结果从现有类型派生 `ToSchema`，不另抄一套业务 DTO。为版本字符串、多边形数组等自定义 Serde 表达补充准确的 schema。
- 上传定义单个 multipart 二进制 `file` 字段和必需的 UUID 幂等头；SSE 定义 text/event-stream、重连与终态语义，并提供真实帧格式示例。
- 依赖版本统一放根 Cargo，验证完整 schema 引用链以及 JSON 与文档的一致性。
