# docparse-cli

Command-line entry points for `docparse parse` and `docparse inspect-model`. Supports JSON and Markdown output, raw/semantic Markdown views, atomic file output, and PNG/SVG diagnostics.

NVIDIA builds use `--features cuda`; layout, OCR, TSR and formula share the compiled backend. TOML does not accept `execution_provider`. See the root `README.md` for complete options and examples.
