# docparse-cli

`docparse parse` 和 `docparse inspect-model` 命令行入口。支持 JSON、plain text、Markdown、raw/semantic view、原子输出文件与 PNG/SVG diagnostics。

NVIDIA builds use `--features cuda`; layout, OCR, TSR and formula share the compiled backend. TOML does not accept `execution_provider`. See the root `README.md` for complete options and examples.
